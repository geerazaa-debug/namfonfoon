กระผม [ชื่อ–นามสกุล] ผู้ดูแลโครงการ "น้ำ ฝน ฝุ่น" ซึ่งเป็นบริการฟรีผ่าน LINE และแผนที่บนเว็บ ไม่มีโฆษณา ไม่เก็บค่าบริการ

โดยทำดังนี้
- ดึงข้อมูลชุดละไม่เกิน 1 ครั้งต่อ 5 นาที แล้วใช้สำเนาเดียวกันสำหรับผู้ใช้ทุกคน และระบุตัวโครงการพร้อมอีเมลติดต่อในทุกคำขอ

- ใช้เพื่อแสดงผลแก่ประชาชนเท่านั้น ไม่ขาย ไม่ให้บริการเชิงพาณิชย์ และระบุชัดว่าไม่ใช่ประกาศทางการ พร้อมแนะนำให้ติดตามประกาศของ กทม.
