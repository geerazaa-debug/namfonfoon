**สิ่งที่ส่งมาด้วย** [สรุปโครงการ / ผลการศึกษาเบื้องต้น จำนวน 1 ชุด]

ด้วย [ชื่อผู้ขอ/หน่วยงาน] ได้พัฒนาต้นแบบระบบแจ้งเตือนฝนตกหนักรายเขตสำหรับประชาชนในกรุงเทพมหานคร ระบบนี้อ้างอิงเกณฑ์ปริมาณฝนจาก "ข้อมูลสถิติน้ำท่วมขังบนถนนสายหลักในความรับผิดชอบของสำนักการระบายน้ำ" (data.bangkok.go.th ชุดข้อมูล `frd_dds` สัญญาอนุญาต CC BY) ปี พ.ศ. 2565–2568 จำนวน 1,434 เหตุการณ์ และได้ระบุแหล่งที่มาของข้อมูลในทุกข้อความแจ้งเตือนแล้ว

จากการทดสอบย้อนหลังด้วยข้อมูลสาธารณะที่มีอยู่ พบว่าสถานีวัดฝนที่เปิดเผยต่อสาธารณะครอบคลุมพื้นที่เขตเพียงบางส่วน ทำให้วันที่มีบันทึกน้ำท่วมขังกว่าครึ่งหนึ่งไม่ปรากฏปริมาณฝนที่สอดคล้องกัน ข้อจำกัดนี้ทำให้ยังไม่สามารถพัฒนาการแจ้งเตือนให้แม่นยำระดับพื้นที่ได้ จึงใคร่ขอความอนุเคราะห์ข้อมูลดังต่อไปนี้

**วัตถุประสงค์และการใช้ข้อมูล**
1. ใช้ทดสอบย้อนหลังและปรับปรุงเกณฑ์แจ้งเตือนฝนตกหนักรายเขต โดยใช้ฤดูฝน พ.ศ. 2569 เป็นชุดทดสอบอิสระ และจะกำหนดเกณฑ์การประเมินไว้ล่วงหน้า
2. ผลการศึกษาและข้อค้นพบที่เป็นประโยชน์ต่อการระบายน้ำ ยินดีส่งมอบให้สำนักการระบายน้ำ
3. ข้อมูลที่ได้รับเป็นข้อมูลทางกายภาพ **ไม่มีข้อมูลส่วนบุคคล** จะจัดเก็บอย่างปลอดภัย ใช้ตามวัตถุประสงค์ที่แจ้งเท่านั้น และจะไม่เผยแพร่ต่อโดยไม่ได้รับอนุญาต
4. จะระบุแหล่งที่มา "สำนักการระบายน้ำ กรุงเทพมหานคร" ทุกครั้งที่ใช้ข้อมูล

**ข้อสอบถามเพิ่มเติม** ขอทราบเงื่อนไขการใช้ข้อมูล (สัญญาอนุญาต) สำหรับ (ก) การศึกษาวิจัย และ (ข) การให้บริการแจ้งเตือนแก่ประชาชนหรือหน่วยงานภายนอก รวมถึงค่าใช้จ่าย (ถ้ามี)

จึงเรียนมาเพื่อโปรดพิจารณาให้ความอนุเคราะห์ จะขอบคุณยิ่ง
